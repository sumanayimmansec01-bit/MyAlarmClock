# จับเวลาหลายรอบ (Multi-round Timer)

เว็บแอพจับเวลาสำหรับมือถือ ตั้งได้หลายรอบต่อกัน เช่น `30, 30`
ครบแต่ละรอบจะมีเสียงเตือน (พร้อมสั่น) เลือกเสียงได้ 4 แบบ: ขันทิเบต, ไม้เคาะ, กริ๊ง 2 โน้ต, บี๊บดิจิทัล และตั้งเสียงจบรอบสุดท้ายแยกได้ แล้วเริ่มรอบถัดไปเอง ครบรอบสุดท้ายหยุดเอง ไม่ต้องกดหยุด

## ใช้งาน
- แตะ `+5 … +60` เพื่อเพิ่มรอบ หรือพิมพ์ `30, 30` / `1:30` (นาที:วินาที) แล้วกด **เพิ่ม**
- กด **เริ่ม** — มีนับถอยหลังก่อนรอบแรกให้จัดท่านั่ง (ปิดได้) ระหว่างจับเวลาแอพจะกันหน้าจอดับ (Wake Lock) และเปลี่ยนเป็นจอมืดเหลือแค่เวลาตัวจาง แตะจอเพื่อแสดงปุ่ม
- รอบที่ตั้งไว้จะถูกจำไว้ในเครื่องสำหรับครั้งถัดไป

## ติดตั้งลงมือถือ
เปิดผ่าน GitHub Pages (Settings → Pages → Deploy from branch) แล้ว
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ไฟล์ทั้งหมดเป็น HTML/JS ล้วน ไม่ต้อง build ใช้งานแบบออฟไลน์ได้หลังเปิดครั้งแรก

## ทดสอบ (E2E)
ใช้ Playwright จำลองหน้าจอ Android (Pixel 7) และ iPhone 14 พร้อมนาฬิกาจำลอง จึงทดสอบรอบ 30 นาทีได้ในไม่กี่วินาที

```bash
npm install
npm run test:e2e
```

## แผนที่พลังงาน (Energy Map) — `energy/`
แอพบันทึกว่ากิจกรรมไหน **เติมพลัง** หรือ **ดูดพลัง** แล้วสรุปเป็น **รายวัน / รายสัปดาห์ / รายเดือน** เปิดที่ `/energy/`
- แตะกิจกรรมสำเร็จรูป 16 อย่าง (หรือเพิ่มเอง) เลือกระดับ ▼▼ ▼ ▲ ▲▲ ระยะเวลา และเวลา (ย้อนหลังได้)
- คะแนน = ระดับ × (นาที ÷ 30) เช่น ประชุม 60 นาที (−2) = −4
- หน้าสรุป: กราฟพลังสุทธิ, ตัวชาร์จ/ตัวดูดพลังอันดับต้น, คำแนะนำอัตโนมัติ (ช่วงเวลาที่พลังดี/ตก, วันที่พลังลด)
- ข้อมูลเก็บในเครื่อง สำรอง/นำเข้าเป็น JSON ได้ ติดตั้งลงหน้าจอหลักและใช้ออฟไลน์ได้
