# จับเวลาหลายรอบ (Multi-round Timer)

เว็บแอพจับเวลาสำหรับมือถือ ตั้งได้หลายรอบต่อกัน เช่น `30, 30`
ครบแต่ละรอบจะมีเสียงเตือน (พร้อมสั่น) เลือกเสียงได้ 5 แบบ: ขันค่อยๆ ดัง (ค่าเริ่มต้น ดังขึ้นจากความเงียบจึงไม่ทำให้ตกใจ), ขันทิเบต, ไม้เคาะ, กริ๊ง 2 โน้ต, บี๊บดิจิทัล ตั้งเสียงจบรอบสุดท้ายแยกได้ และปรับความดังได้ 3 ระดับ แล้วเริ่มรอบถัดไปเอง ครบรอบสุดท้ายหยุดเอง ไม่ต้องกดหยุด

## ใช้งาน
- หน้าแรกอยู่ในจอเดียว: วงเวลา, แถบรอบ (ยาวตามจำนวนนาที) และปุ่มเริ่มวงกลม
- แตะรอบในแถบเพื่อแก้ (− / + ทีละ 5 นาที, เลือก 15–60, พิมพ์เอง หรือลบ) แตะ **＋** เพื่อเพิ่มรอบ
- **⚙ ตั้งค่า** ใช้เลือกเสียง ความดัง นับถอยหลัง และจอมืด
- ในช่องพิมพ์ใส่ได้หลายรอบพร้อมกัน เช่น `30, 30` หรือใส่วินาทีแบบ `1:30`
- กด **เริ่ม** — มีนับถอยหลังก่อนรอบแรกให้จัดท่านั่ง (ปิดได้) ระหว่างจับเวลาแอพจะกันหน้าจอดับ (Wake Lock) และเปลี่ยนเป็นจอมืดเหลือแค่เวลาตัวจาง แตะจอเพื่อแสดงปุ่ม
- รอบที่ตั้งไว้จะถูกจำไว้ในเครื่องสำหรับครั้งถัดไป

## ติดตั้งลงมือถือ
เปิดผ่าน GitHub Pages (Settings → Pages → Deploy from branch) แล้ว
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ไฟล์ทั้งหมดเป็น HTML/JS ล้วน ไม่ต้อง build ใช้งานแบบออฟไลน์ได้หลังเปิดครั้งแรก

## ทดสอบ (E2E)
ใช้ Playwright จำลองหน้าจอ Android (Pixel 7) และ iPhone 14 พร้อมนาฬิกาจำลอง จึงทดสอบรอบ 30 นาทีได้ในไม่กี่วินาที

```bash
npm install
npm run test:e2e
# ถ้ามี Chromium ติดตั้งไว้แล้ว: CHROMIUM_PATH=/path/to/chrome npm run test:e2e
```
