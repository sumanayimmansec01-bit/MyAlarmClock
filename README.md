# จับเวลาหลายรอบ (Multi-round Timer)

## แอพ Android (แนะนำสำหรับนั่งสมาธิ)
ดาวน์โหลด APK ล่าสุด: https://github.com/sumanayimmansec01-bit/MyAlarmClock/releases/tag/android-latest

- ใช้ระบบนาฬิกาปลุกของเครื่อง (exact alarm) ปลุกทุกครั้งที่ครบรอบ แม้ล็อกจอ ปัดแอพทิ้ง หรือรีสตาร์ทเครื่อง
- เสียงเตือนเล่นผ่านช่องเสียงนาฬิกาปลุกด้วยระดับเสียงของแอพเอง ดังได้แม้ปิดเสียงเรียกเข้า/สื่อ หรือเปิดโหมดสั่น
- ไม่ต้องเปิดจอค้าง ระหว่างจับเวลาแอพไม่ทำงานเลย เวลานับถอยหลังบนหน้าจอล็อกเป็นของระบบ จึงแทบไม่กินแบต
- โค้ดอยู่ในโฟลเดอร์ `android/` และ GitHub Actions สร้าง APK ให้ทุกครั้งที่มีการแก้ไข

### ข้อจำกัดที่แอพแก้ไม่ได้
- กด **บังคับหยุด (Force stop)** ในการตั้งค่าแอพ จะลบนาฬิกาปลุกทั้งหมด
- โหมดห้ามรบกวนแบบ **ปิดเสียงทั้งหมด (Total silence)** ปิดเสียงนาฬิกาปลุกด้วย
- มือถือบางยี่ห้อ (Xiaomi, OPPO, vivo ฯลฯ) อาจต้องอนุญาต "เริ่มอัตโนมัติ" เพื่อให้ตั้งเวลาต่อหลังรีสตาร์ทเครื่อง

## เว็บแอพ

เว็บแอพจับเวลาสำหรับมือถือ ตั้งได้หลายรอบต่อกัน เช่น `30, 30`
ครบแต่ละรอบจะมีเสียงเตือน 1 ครั้ง (พร้อมสั่น) เลือกเสียงได้ 2 แบบ: กริ๊ง 2 โน้ต, บี๊บดิจิทัล แล้วเริ่มรอบถัดไปเอง ครบรอบสุดท้ายหยุดเอง ไม่ต้องกดหยุด

## ใช้งาน
- แตะ `+5 … +60` เพื่อเพิ่มรอบ หรือพิมพ์ `30, 30` / `1:30` (นาที:วินาที) แล้วกด **เพิ่ม**
- กด **เริ่ม** — ระหว่างจับเวลาแอพจะกันหน้าจอดับ (Wake Lock) ควรเปิดหน้านี้ค้างไว้
- รอบที่ตั้งไว้จะถูกจำไว้ในเครื่องสำหรับครั้งถัดไป

## ติดตั้งลงมือถือ
เปิดผ่าน GitHub Pages (Settings → Pages → Deploy from branch) แล้ว
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ไฟล์ทั้งหมดเป็น HTML/JS ล้วน ไม่ต้อง build ใช้งานแบบออฟไลน์ได้หลังเปิดครั้งแรก

## ทดสอบ (E2E)
ใช้ Playwright จำลองหน้าจอ Android (Pixel 7) และ iPhone 14 พร้อมนาฬิกาจำลอง จึงทดสอบรอบ 30 นาทีได้ในไม่กี่วินาที

```bash
npm install
npm run test:e2e
```
