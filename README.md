# จับเวลาหลายรอบ (Multi-round Timer)

เว็บแอพจับเวลาสำหรับมือถือ ตั้งได้หลายรอบต่อกัน เช่น `30, 30`
ครบแต่ละรอบจะมีเสียงเตือน 1 ครั้ง (พร้อมสั่น) แล้วเริ่มรอบถัดไปเอง ครบรอบสุดท้ายหยุดเอง ไม่ต้องกดหยุด

## ใช้งาน
- แตะ `+5 … +60` เพื่อเพิ่มรอบ หรือพิมพ์ `30, 30` / `1:30` (นาที:วินาที) แล้วกด **เพิ่ม**
- กด **เริ่ม** — ระหว่างจับเวลาแอพจะกันหน้าจอดับ (Wake Lock) ควรเปิดหน้านี้ค้างไว้
- รอบที่ตั้งไว้จะถูกจำไว้ในเครื่องสำหรับครั้งถัดไป

## ติดตั้งลงมือถือ
เปิดผ่าน GitHub Pages (Settings → Pages → Deploy from branch) แล้ว
- Android (Chrome): เมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

ไฟล์ทั้งหมดเป็น HTML/JS ล้วน ไม่ต้อง build ใช้งานแบบออฟไลน์ได้หลังเปิดครั้งแรก
